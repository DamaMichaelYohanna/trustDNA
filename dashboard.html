Developer Integration Guide

Integrate real-time fraud scoring in under 15 minutes.

1. Client-Side Telemetry Collector (HTML / React / Vue)

<script src="http://localhost:8000/v1/trustdna.js"></script> <script> const trustdna = TrustDNA.init({ publishableKey: 'td_pub_test_...' }); // Attach token to form submit or API payload const token = await trustdna.getTelemetryToken(); </script>

2. Backend Risk Decision (Python)

import trustdna client = trustdna.TrustDNAClient(secret_key="td_sec_test_...") decision = client.risk.evaluate( customer_id="usr_82931", telemetry_token=request.form["td_token"], amount=1500.0, currency="USD" ) if decision.decision == "block": raise PermissionDenied("Transaction blocked by TrustDNA")

3. Backend Risk Decision (Node.js)

const TrustDNA = require('@trustdna/node'); const client = new TrustDNA({ secretKey: 'td_sec_test_...' }); const decision = await client.risk.evaluate({ customerId: 'usr_82931', telemetryToken: req.body.td_token, amount: 1500.0, currency: 'USD' }); if (decision.decision === 'block') { return res.status(403).json({ error: 'Transaction rejected by TrustDNA' }); }
